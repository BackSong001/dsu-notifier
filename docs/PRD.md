# PRD: DSU Notifier

## 1. 제품 개요

동서대학교 공지사항을 자동으로 수집하고, 새 공지가 등록되면 개인 사용자의 모바일 기기에 푸시 알림을 제공한다.

## 2. 목표

- 동서대학교 주요 게시판의 공지를 한 곳에서 확인한다.
- 새 공지를 운영에서는 최대 10분 이내 감지한다. 테스트에서는 30초 주기로 감지한다.
- 같은 공지와 같은 알림을 중복 처리하지 않는다.
- 개인 사용자가 로그인 없이 바로 사용할 수 있게 한다.

## 3. 대상 게시판

`docs/dsu_url.md` 기준:

| 게시판 | URL |
|---|---|
| 학사 | `https://www.dongseo.ac.kr/kr/?pCode=MN2000194` |
| 공지/행사 | `https://www.dongseo.ac.kr/kr/index.php?pCode=MN2000191` |
| 취업 | `https://www.dongseo.ac.kr/kr/index.php?pCode=job_plus` |
| 모집 | `https://www.dongseo.ac.kr/kr/index.php?pCode=MN2000197` |
| 장학 | `https://www.dongseo.ac.kr/kr/index.php?pCode=MN2000195` |
| 입찰 | `https://www.dongseo.ac.kr/kr/index.php?pCode=MN2000196` |

컴퓨터공학부 게시판은 URL이 없으므로 제외한다.

## 4. 사용자 기능

- 게시판별 공지 목록 조회
- 공지 상세 페이지 열기
- 게시판별 푸시 알림 켜기/끄기
- 앱 알림 권한 요청 및 상태 안내
- 공지의 제목, 조회수, 등록일, 번호 등 목록 정보 표시

## 5. 자동화 기능

- 최초 배포 시 기존 공지 목록 수집
- 10분마다 게시판 최신 목록 수집
- 새 공지 DB 저장
- 알림이 활성화된 디바이스에 새 공지 푸시
- 수집 및 발송 실패 기록
- 첫 페이지에서 사라진 고정 공지를 `failed` 상태로 표시하고, 다시 나타나거나 새로 발견되면 `true` 상태로 표시

## 6. 비기능 요구사항

- 공지 중복 저장 금지
- 알림 중복 발송 금지
- 수집기 동시 실행 안전성 보장
- 비밀키의 클라이언트·Git·로그 노출 금지
- 수집 실패 시 기존 정상 데이터 보존

## 7. 제외 범위

- Google 로그인 및 사용자 계정
- 다중 사용자 계정별 데이터 동기화
- 관리자 웹 화면
- 공지 본문·첨부파일의 별도 저장
- 컴퓨터공학부 게시판

## 8. 성공 기준

- 6개 게시판을 정상 수집한다.
- 새 공지가 다음 수집 주기에 저장된다.
- 새 공지당 디바이스별 알림이 최대 1회 발송된다.
- 수집 실패가 기존 공지 데이터에 영향을 주지 않는다.
