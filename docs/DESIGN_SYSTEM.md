# DSU Notifier 디자인 시스템

동서대학교 공지사항 앱의 모바일 UI 기준 문서다. 제공된 초안 이미지는 레이아웃과 정보 배치 참고로만 사용하며, 색상 값은 프로젝트 루트의 `colors.json`을 단일 기준으로 사용한다.

## 1. 디자인 원칙

- 공지 탐색과 알림 설정을 가장 짧은 동선으로 제공한다.
- Android 모바일을 우선하고, 작은 화면에서 가로 스크롤을 만들지 않는다.
- 제목·등록일·조회수·번호를 한눈에 비교할 수 있게 정보 계층을 유지한다.
- 선택·고정·알림 상태는 색상만으로 전달하지 않고 텍스트나 아이콘을 함께 사용한다.
- 추후 기능은 현재 제공 기능과 혼동되지 않도록 비활성 또는 예정 상태로 표시한다.

## 2. 색상 토큰

모든 색상은 `colors.json`의 값을 사용한다. 아래 값은 현재 문서의 의미상 별칭이다.

| 토큰 | 값 | 사용처 |
|---|---|---|
| `primary.DEFAULT` | `#E11837` | 선택된 메뉴, 주요 버튼, 현재 페이지, 활성 알림 |
| `primary.hover` | `#C91430` | 주요 버튼 hover 또는 pressed 상태 |
| `primary.active` | `#A91028` | 주요 버튼 active 상태 |
| `primary.light` | `#FCE8EC` | 고정·알림 강조 배경 |
| `secondary.DEFAULT` | `#333333` | 보조 버튼과 보조 UI |
| `background.secondary` | `#F7F7F8` | 목록 화면 배경 |
| `background.tertiary` | `#F0F1F3` | 검색·페이지네이션 보조 영역 |
| `surface.DEFAULT` | `#FFFFFF` | 공지 카드, 검색 입력, 메뉴 패널 |
| `surface.muted` | `#F3F4F6` | 비활성·보조 영역 |
| `text.primary` | `#222222` | 제목과 주요 텍스트 |
| `text.secondary` | `#555555` | 작성자·등록일·게시판명 |
| `text.tertiary` | `#777777` | 조회수·페이지 보조 정보 |
| `text.muted` | `#999999` | 비활성 텍스트 |
| `border.DEFAULT` | `#DDDDDD` | 카드와 입력 필드 기본 테두리 |
| `border.focus` | `#E11837` | 키보드 포커스 테두리 |
| `status.success` | `#218838` | 알림 설정 저장 성공 |
| `status.warning` | `#E6A23C` | 알림 권한 안내 |
| `status.error` | `#DC3545` | API·검색·알림 설정 오류 |
| `interactive.focusRing` | `#E11837` | 키보드·접근성 포커스 링 |

초안 이미지에 보이는 파란색은 레이아웃 참고용이다. 구현 시 브랜드 primary와 보조 색상은 `colors.json`을 우선한다.

## 3. 앱 구조

### 상단 영역

- 왼쪽: 메뉴 버튼
- 중앙: `동서대학교` 타이틀 또는 로고
- 오른쪽: 알림 설정 진입 버튼

### 메뉴

메뉴에는 다음 항목을 제공한다.

1. 공지사항
2. 학사별 공지사항 — 추후 예정
3. 알람설정
4. 저장된 공지
5. 키워드 알람 — 추후 예정

현재 구현 범위에서는 `공지사항`, `알람설정`, `저장된 공지`를 활성 메뉴로 제공한다. 예정 기능은 비활성 상태와 `추후 예정` 텍스트를 함께 표시한다.

### 게시판 선택

공지사항 화면의 대표 게시판은 다음과 같다.

- 학사
- 공지/행사
- 취업
- 모집
- 장학
- 입찰

게시판명은 기존 프로젝트의 `docs/dsu_url.md`와 `BOARDS` 정의를 따른다. 초안의 `위업`은 기존 게시판 명칭인 `취업`으로 표기한다.

## 4. 컴포넌트 명세

### `AppBar`

메뉴 버튼, 앱 타이틀, 알림 설정 버튼을 제공한다. 아이콘 버튼에는 `메뉴`, `알림 설정` 접근성 레이블을 사용한다.

### `NavigationMenu`

메뉴 열기·닫기와 현재 메뉴 선택을 담당한다. 예정 기능은 선택할 수 없으며, 사용자가 현재 제공 범위를 알 수 있도록 예정 상태를 표시한다.

### `BoardTabs`

게시판을 전환한다. 선택된 탭은 `primary.DEFAULT`와 하단 강조선으로 표시하며, 선택되지 않은 탭은 `text.secondary`를 사용한다.

### `SearchBar`

- 검색 입력 필드와 검색 버튼으로 구성한다.
- placeholder: `검색어를 입력해 주세요`
- 검색 실행 시 현재 게시판과 검색어를 유지한다.
- 빈 검색어는 전체 목록을 표시한다.
- 오류 발생 시 입력값을 보존하고 재시도할 수 있어야 한다.

### `NoticeCard`

공지 하나를 다음 순서로 표시한다.

1. 고정 공지 배지
2. 공지 제목
3. 작성자와 등록일
4. 조회수와 번호

번호가 `null`인 고정 공지는 숫자 대신 `고정`을 표시한다. 카드 선택 시 해당 공지의 상세 URL을 외부 브라우저로 연다.

### `BoardAlarmButton`

현재 게시판 제목 오른쪽에 표시하며, 해당 게시판 전체의 신규 공지 알림을 켜거나 끄는 버튼이다.

- 비활성: 알림 꺼짐 아이콘
- 활성: `primary.DEFAULT` 알림 아이콘과 활성 상태
- 저장 중: 중복 입력 방지
- 저장 실패: 기존 상태 유지와 오류 안내

### `AlarmSettingsList`

알람을 켠 게시판을 카드로 표시한다. 각 카드에서 게시판 알림을 끌 수 있다. 알람 설정 게시판이 없으면 빈 목록 안내를 표시한다.

### `SavedNoticeButton`

공지 카드 오른쪽에 별표 아이콘으로 표시하며, 공지를 저장하거나 저장 취소한다.

### `SavedNoticeList`

별표를 누른 공지를 공지 카드 형태로 표시한다. 저장된 공지가 없으면 빈 목록 안내를 표시한다.

### `Pagination`

- 한 페이지에 공지 19개를 표시한다.
- 페이지 이동기는 목록 최하단에 둔다.
- 이전·다음 버튼과 페이지 번호를 제공한다.
- 현재 페이지는 `primary.DEFAULT` 배경과 `primary.foreground` 텍스트로 강조한다.
- 첫 페이지에서는 이전 버튼을 비활성화한다.
- 마지막 페이지에서는 다음 버튼을 비활성화한다.
- 페이지 변경 시 현재 게시판과 검색어를 유지한다.

### 상태 컴포넌트

- `LoadingState`: 목록을 불러오는 동안 표시
- `EmptyState`: 결과가 없을 때 안내와 검색 초기화 또는 새로고침 제공
- `ErrorState`: English error code는 보존하고 사용자 안내는 한국어로 표시
- `PermissionState`: Android 알림 권한 거부 시 설정 이동 안내 제공

## 5. 화면 상태와 데이터

공지 목록 화면은 다음 상태를 가진다.

| 상태 | 설명 |
|---|---|
| `selectedMenu` | 현재 메뉴 |
| `selectedBoard` | 현재 게시판 코드 |
| `query` | 검색어 |
| `page` | 현재 페이지 번호 |
| `totalCount` | 전체 검색 결과 수 |
| `notices` | 현재 페이지의 공지 0~19개 |
| `alarmBoards` | 알림이 활성화된 게시판 집합 |
| `requestState` | loading, success, empty, error |

검색·게시판 전환·페이지 전환은 목록 요청을 다시 수행하고, 페이지 크기는 항상 19로 유지한다.

## 6. 접근성 및 터치 기준

- 아이콘과 버튼의 터치 영역은 최소 48dp로 한다.
- 아이콘 버튼에는 의미 있는 접근성 레이블을 제공한다.
- 포커스 상태는 `border.focus` 또는 `interactive.focusRing`으로 표시한다.
- 고정 공지와 알림 활성 상태는 배지·아이콘·텍스트를 함께 사용한다.
- 본문과 배경은 `colors.json`의 대비 가능한 조합을 사용한다.
- 긴 제목은 카드 내부에서 자연스럽게 여러 줄로 표시하며 레이아웃을 깨지 않게 한다.

## 7. 현재 범위와 추후 범위

현재 범위:

- 대표 게시판 탭
- 공지 목록과 검색
- 페이지당 19개와 하단 페이지네이션
- 공지별 게시판 알림 설정
- 알람 설정 게시판 목록
- 저장된 공지 목록
- 공지 상세 URL 열기

추후 범위:

- 학사별 공지사항
- 키워드 알람
- 공지 본문을 앱 내부에서 직접 표시

색상·간격·컴포넌트 구현이 변경되면 이 문서와 `colors.json`을 함께 갱신한다.
